## 路由和延迟：第三方实测给了什么数字

先说 Pro。它的路由是三网回程都经香港 CTG 接回国内 CN2 GIA，电信去程直接走 CN2 GIA 到香港 CTG，联通走 AS4837 + AS10099，移动走 CMI。第三方测评机构在不同时间点公布的国内三网平均延迟大致在 43–49ms 这个区间，其中电信、联通通常落在 42ms 左右，移动约 46ms，丢包很低。这个数据是测评机构的结果，不是商家承诺的 SLA。

Standard（原 Lite）走的是另一条路：三网回程中国移动 CMI，IPv6 回程也是 CMI 方向。有站长实测到深圳的延迟能压到 10ms 出头，这个数字对香港机房来说相当好看。不过要注意，DMIT 官网并没有标注这条线路接入 CMI，是用户实测出来的结果，官方对去程做过说明，大意是新 IP 段的 prefix 过白需要时间。

Eyeball 的情况更有意思。移动方向是双程 CMI，电信去程走 CN2、回程 163pp，联通回程是 CUG + CMI 动态负载，去程基本没优化。第三方测到的国内延迟普遍落在 30–70ms，比 T1 强，和 Pro 有明确差距。问题是 DMIT 官方把 HKG.EB 明确标成了 Beta，并提示路由和性能可能持续调整，也不建议用于对稳定性要求高的生产环境。近期多个第三方渠道的信息显示，这条产品线已经下线或长期没有补货，实际是否还能下单，要看官网库存。

Tier 1 则是彻底的另一个物种。它接的是国际线路，包括 RETN 这类骨干，香港到欧洲的延迟表现比同类产品好很多，但对中国大陆没有任何专项优化。电信用户买 T1 要特别小心，实测里出现过延迟比美国机房还高的情况。它的卖点是便宜、端口大、流量多，不是回国快。

## 买之前必须知道的几个坑

**IP 有可能不通。** 这是所有海外 VPS 都会遇到的问题，DMIT 的处理方式是多渠道提到的两档：下单时可以选择外加 $1 的 Guarantee+ 保障，确保拿到的 IP 可用；如果没买保障又碰上 IP 在国内连不上，换 IP 的费用通常按 $5 一次计算。这两条规则随政策可能调整，付款前建议在购买页自己确认一遍当前说明。

**Eyeball 是 Beta。** 官方措辞很清楚：路由和性能都可能继续变，不建议拿来做对稳定性要求高的业务。如果你的项目已经上线，别因为便宜十美元就去赌它的线路。

**T1 不要买给国内用户看。** 这条线路的存在意义是国际互联和大流量，不是回国快。电信用户在 T1 上遇到高延迟是正常现象，不是故障。
